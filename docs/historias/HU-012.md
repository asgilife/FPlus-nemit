# HU-012 — Registrar el resultado de la tercería y obtener el ensaye final

**Como** usuario de Fresnillo que revisa ensayes **quiero** registrar el resultado del laboratorio tercero solo para los elementos enviados y obtener el ensaye final con la regla del contrato **para** no capturar a mano y evitar «algún error de captura» (RF-066).

- **Requisitos:** RF-021, RF-065, RF-066, RF-067, RF-068
- **Por qué esa prioridad:** Cierra el análisis de tercería de esta etapa.
- **Depende de:** HU-011, P-011, P-032, P-033

**Criterios de aceptación (de negocio):**
- [ ] El lote muestra qué laboratorio tercero le corresponde por su fecha de cierre; se puede cambiar por excepción.
- [ ] Solo se registran resultados de los lotes y elementos que se enviaron a tercería.
- [ ] Cuando el laboratorio indica que «la plata incluye oro» o que «el zinc incluye cadmio», el valor se corrige; si ya viene «zinc corregido», no se corrige otra vez.
- [ ] Con el resultado del tercero, el ensaye final del elemento es el que dicta la regla del extracto (con Met-Mex, el de en medio).
- [ ] Después de la tercería ya no se ofrece el promedio negociado.
- [ ] El archivo del tercero, la imagen de su correo y su hoja de trabajo quedan como evidencia.

**Casos de abuso:** Un usuario intenta registrar un resultado de tercería para un elemento que no se envió, o subir como evidencia un archivo ejecutable: el sistema lo rechaza.
