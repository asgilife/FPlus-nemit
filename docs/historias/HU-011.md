# HU-011 — Decidir por elemento: promediar, aceptar un ensaye o ir a tercería

**Como** administrador de contratos **quiero** registrar la decisión final de cada elemento (resultado negociado), aunque el sistema sugiera otra **para** que quede registrado y que «el sistema no va a tomar las decisiones por ellos» (sesión 2, 01:49:27).

- **Requisitos:** RF-061, RF-062
- **Por qué esa prioridad:** Completa el análisis de intercambio.
- **Depende de:** HU-010, P-031 (y C-009)

**Criterios de aceptación (de negocio):**
- [ ] La columna RN toma el valor de INT y se puede cambiar.
- [ ] Cada elemento se resuelve por separado: un elemento puede quedar promediado mientras otro sigue en tercería.
- [ ] Las opciones son promediar, aceptar el ensaye de una de las partes o tercería; no se escribe un valor intermedio arbitrario.
- [ ] Queda registrado quién decidió y cuándo.

**Casos de abuso:** Un usuario sin el rol de administrador de contratos intenta cambiar el resultado negociado: no puede.
