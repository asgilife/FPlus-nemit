# HU-014 — Dar acceso a los usuarios con los roles que les tocan

**Como** responsable de dar accesos (por definir, P-050) **quiero** crear roles, asignarles tareas y asignar roles a cada usuario de Fresnillo y de ERSA **para** que los roles «no queden fijos, sino que pueden ser configurados» (RF-100).

- **Requisitos:** RF-100, RNF-004, RNF-005, RNF-006
- **Por qué esa prioridad:** Necesaria para que entren los usuarios de ERSA y de Fresnillo; la propusimos nosotros y el cliente la aceptó.
- **Depende de:** P-021, P-050, lista de roles que entregará el cliente

**Criterios de aceptación (de negocio):**
- [ ] Se crean roles y a cada uno se le asignan tareas; a cada usuario se le asignan uno o más roles.
- [ ] Los usuarios de Fresnillo entran con su usuario corporativo; los de ERSA, con un usuario externo.
- [ ] Un usuario de ERSA solo ve lo de Fresnillo y solo sus tareas.

**Casos de abuso:** Un usuario intenta darse un rol a sí mismo o entrar a una tarea de otro rol escribiendo su dirección: no puede. Un usuario de ERSA intenta entrar con una cuenta corporativa ajena o probar contraseñas: el sistema lo bloquea y lo registra.
