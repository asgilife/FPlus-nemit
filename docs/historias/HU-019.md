# HU-019 — Llevar el ciclo de vida del extracto

**Como** administrador de contratos **quiero** numerar, revisar, autorizar, copiar y sustituir extractos y crear extractos de lotes específicos **para** «plasmar lo que dice el contrato» con control, como lo hacían en Met-Mex (sesión 4, P1 00:37:35).

- **Requisitos:** RF-026, RF-027, RF-028, RF-029, RF-030, RF-031, RF-032, RF-033, RF-034
- **Por qué esa prioridad:** Alcance por confirmar (P-053); el de lotes específicos «casi no se usaría» (sesión 4, P1 00:47:26).
- **Depende de:** HU-005, P-053, C-008

**Criterios de aceptación (de negocio):**
- [ ] Cada extracto recibe un número consecutivo y pasa por generar, revisar y autorizar; solo uno autorizado se aplica.
- [ ] Se puede crear un extracto copiando otro.
- [ ] Un extracto puede sustituir a otro y queda registrado cuál sustituye a cuál.
- [ ] Un extracto de lotes específicos se liga a su extracto base, se aplica solo a los lotes elegidos y, autorizado, ya no admite lotes.
- [ ] A cada lote le aplica un solo extracto.
- [ ] La consulta de extractos muestra términos, estado, fechas y sustituciones.

**Casos de abuso:** Quien generó un extracto intenta autorizarlo él mismo: no puede (pendiente de confirmar con el cliente).
