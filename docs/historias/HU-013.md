# HU-013 — Registrar una tercería anómala y la historia de sus resultados

**Como** usuario de Fresnillo que revisa ensayes **quiero** registrar un nuevo resultado del tercero (otro sobre, reensaye, análisis en conjunto) y ver cuál es el vigente **para** conservar «toda esa trazabilidad» que hoy vive en comentarios de Excel (RF-070).

- **Requisitos:** RF-069, RF-070
- **Por qué esa prioridad:** Excepción poco frecuente: «nos ha pasado dos veces» (sesión 2, 00:14:45).
- **Depende de:** HU-012

**Criterios de aceptación (de negocio):**
- [ ] Para un mismo lote y elemento se pueden registrar resultados sucesivos (primer resultado, reensaye, análisis en conjunto, análisis posterior), cada uno con su fecha.
- [ ] Uno de ellos queda marcado como vigente y los demás se conservan.
- [ ] Si Met-Mex ya no tiene sobre, se indica que el caso pasa a remuestreo.
