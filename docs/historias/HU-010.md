# HU-010 — Cargar los ensayes de Met-Mex y ver qué se promedia y qué va a tercería

**Como** usuario de Fresnillo que revisa ensayes **quiero** subir el Excel de Met-Mex tal como llega y ver por elemento la diferencia, el límite de partición y si toca promedio o tercería **para** evitar «errores de que me equivoqué, lo teclé» (sesión 2, 01:36:34).

- **Requisitos:** RF-020, RF-060, RF-061, RF-064, RF-065
- **Por qué esa prioridad:** Es el análisis de intercambio que el cliente pidió para esta etapa.
- **Depende de:** HU-005, HU-009, P-030

**Criterios de aceptación (de negocio):**
- [ ] Se sube el Excel de Met-Mex tal como llega; la plata en kg/t se convierte a g/t.
- [ ] Si Met-Mex cambió el formato, el sistema avisa en lugar de cargar datos equivocados.
- [ ] Por elemento se ven el ensaye de Met-Mex, el de la unidad (ERSA), la diferencia (DIF), el límite de partición del extracto y la marca P o T (INT).
- [ ] Por lote se ven tipo de muestra, lotes, fecha de cierre, peso seco, fecha de intercambio, fecha de tercería y laboratorio tercero.
- [ ] El Excel de Met-Mex y la imagen de su correo quedan guardados como evidencia del intercambio.

**Casos de abuso:** Un usuario sube un archivo que no es Excel, uno enorme o uno con macros: el sistema lo rechaza sin procesarlo. Una evidencia solo la pueden ver quienes tienen acceso al lote.
