# Informes de avance

Los escribe `nemit:pmo` para quien no sigue las fichas día a día: cuánto va, cuánto falta, qué riesgos hay y qué sigue.
El avance se cuenta en sesiones de trabajo, desde las fichas, y cada actualización verifica lo que el informe anterior
afirmaba. Formato y fuentes en `.claude/perfil.md` § Informe de avance.
