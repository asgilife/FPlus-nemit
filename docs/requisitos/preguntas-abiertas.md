# Preguntas abiertas para el cliente

Lo que no se puede decidir sin el cliente. Se lleva a la siguiente junta y la respuesta se anota aquí, con fecha y quién
respondió (por rol), y se baja al requisito que corresponde.

Están **ordenadas por lo que deciden**: primero las que definen el alcance o la viabilidad, después las que bloquean
varios requisitos y al final las de detalle. Los números no siguen ese orden porque los requisitos ya los citan.
